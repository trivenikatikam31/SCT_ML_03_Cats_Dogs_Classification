# SCT_ML_03 - Cats vs Dogs Image Classification using SVM

## 📌 Overview
This project is completed as part of the **SkillCraft Technology Machine Learning Internship**.

The objective of this project is to build an image classification model that can distinguish between **cats** and **dogs** using a **Support Vector Machine (SVM)** classifier.

---

## 🎯 Objective

Develop an image classifier using SVM by preprocessing image data and evaluating the model's performance.

---

## 🛠️ Technologies Used

- Python
- Google Colab
- OpenCV
- NumPy
- Scikit-learn
- Matplotlib

---

## 📂 Dataset

The Cats and Dogs dataset contains images belonging to two classes:
- Cats
- Dogs

The images were resized to **64 × 64 pixels** and converted into flattened feature vectors before training.

---

## ⚙️ Project Workflow

1. Import required libraries
2. Load the dataset
3. Resize images
4. Convert images into feature vectors
5. Prepare training and testing data
6. Train the Support Vector Machine (SVM) model
7. Predict test images
8. Evaluate model performance using:
   - Accuracy Score
   - Classification Report
   - Confusion Matrix

---

## 📊 Results

The SVM model successfully classified cat and dog images after preprocessing and feature extraction.
